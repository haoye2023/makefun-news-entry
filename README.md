Entry for the make.fun bounty [One image that sums up the news of
20 November 2026](https://make.fun/bounty/news-image-20261120).

`main.py` — pure Python standard library, no network — draws a newspaper
front page carrying 30 stories from Friday 20 November 2026: a numbers
strip, three lead stories with program-drawn illustrations, twelve short
reports and a 15-item "Also on Friday" list, plus a date-check line.
It writes a deterministic 1024x1024 `entry.png` (two runs are
byte-identical).

Run it:

    MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
