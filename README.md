# The World in a Day — 20 November 2026

`main.py` is a dependency-free Python program (standard library only) that
generates a one-image summary of the world news of Friday 20 November 2026 —
the Shenzhen trilateral summit, the strikes on Kyiv, the World Court's
genocide finding on Myanmar, the Hormuz standoff, the COP31 deadlock, and
Voyager 1's call from one light-day away — and writes it as a 1024x1024 PNG
to `/output/entry.png` (or to the directory named by the `MAKEFUN_OUTPUT_DIR`
environment variable). It uses no network and no clock, so every run produces
a byte-identical image.
